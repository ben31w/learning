# JavaScript-Practice
Introduction to JavaScript.

All Vanilla JS. No frameworks.

I started this effort around 2023, taking inspiration from "A Smarter 
Way to Learn JavaScript". 

Best starting point might be hello.html + hello.js. These examples are very 
simple, and I've tried to annotate them and keep them in good modern practice.

Old starting point that could still be helpful is index.html + index.js. These
are less organized and include some poor practices like inline event handling (ex:
onclick, onsubmit, etc.)
