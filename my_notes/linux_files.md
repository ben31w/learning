# Important Linux Files

## Network
- `/etc/hosts`
  - Local mappings of IP address -> host name

- `/etc/resolv.conf`
  - Defines nameserver and search domain

- `/etc/nsswitch.conf`
  - Defines prefered method to resolve hosts (files, dns)

## Startup Profiles

- `~/.bashrc`
  - Executed by bash for non-login shells
  - Can define aliases here
  - You must run `source ~/.bashrc` after you edit the file to apply the changes.

- `~/.vimrc`
  - Vim startup profile
  - Add this `:color desert`
